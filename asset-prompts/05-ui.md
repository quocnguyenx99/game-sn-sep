# 05 · UI: logo, bánh kem, ảnh bìa thẻ game

Nút bấm, panel, icon, bảng điểm, bong bóng thoại và confetti **đã được vẽ bằng CSS/SVG** trong game (nét bóng kiểu kẹo, chạy mượt, sắc nét ở mọi độ phân giải), nên **không cần tạo ảnh**. Các asset dưới đây chỉ để tăng độ đẹp và đều là tuỳ chọn.

Dán `STYLE BLOCK` từ `00-style-guide.md` vào trước.

## 1. `logo-title.png`: chữ tiêu đề (khoảng 1600 × 400, nền trong suốt)

```
[STYLE BLOCK]
Game title logo lettering in Vietnamese: "Hành trình quay về tuổi thơ".
Chunky rounded bubbly 3D letters, white letter faces with a thick royal-blue (#1E4FD8) outline
and a deeper blue (#12318F) extruded bottom edge, glossy highlights, a few small yellow stars
and a tiny paper kite decorating the corners, slight playful wave baseline, one line,
transparent background, 1600x400. All Vietnamese diacritics must be correct and clearly visible.
```

> Mô hình ảnh dễ viết sai dấu tiếng Việt. Hãy **kiểm tra kỹ từng dấu** (à, ì, ề, ổ, ơ). Nếu không đạt, bỏ qua file này vì game đã có tiêu đề dựng bằng font Baloo 2.
