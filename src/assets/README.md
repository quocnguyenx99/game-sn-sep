# Asset của game

Chép file **đúng tên** vào các thư mục dưới đây, game sẽ tự dùng mà không cần sửa code. Xem prompt và chuẩn thiết kế trong `asset-prompts/`.

```
images/mascot/  cat-{gold|orange}-{wave|think|win|lose|cake}.png
images/caro/    piece-x.png, piece-o.png
images/oaq/     stone-a.png … stone-e.png, quan.png, board.png
images/bg/      menu.png, caro-desk.png, oaq-banyan.png        (1920×1080)
images/ui/      logo-title.png, cake.png, card-caro.png, card-oaq.png
audio/          bgm-chiptune.mp3, bgm-birthday.mp3, sfx-*.mp3  (xem asset-prompts/06-audio-sources.md)
```

Chấp nhận `.webp` / `.png` / `.jpg` / `.svg` cho ảnh (ưu tiên theo thứ tự đó) và `.mp3` / `.ogg` / `.m4a` / `.wav` cho âm thanh.
